This library is used in games such as Horizon Forbidden West and Death Stranding 2

29、[code-review-graph](https://hellogithub.com/en/periodical/statistics/click?target=https://github.com/tirth8205/code-review-graph)：Graph Tool to Help AI Read Less Code.This is a local-first code intelligence graph tool designed specifically for MCP and CLI. When a file is modified, it can trace through the graph to find affected callers and dependent code, providing more precise context and avoiding token waste from reading the entire codebase.
