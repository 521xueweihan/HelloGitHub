34、[pipecat](https://hellogithub.com/periodical/statistics/click?target=https://github.com/pipecat-ai/pipecat)：实时语音 AI 智能体的框架。这是一个用于构建实时语音和多模态对话智能体的 Python 框架，可将语音识别、大模型和语音合成编排成可组合的处理管道。它通过 WebSocket 或 WebRTC 实现超低延迟交互，每条管道即一个 Agent，支持任务交接、并行分发和跨进程分布式部署等多智能体协作方式，适用于语音助手、在线客服和陪伴应用等场景。

<p align="center"><img src='https://raw.githubusercontent.com/521xueweihan/img4/master/hellogithub/125/736272311.png' style="max-width:80%; max-height=80%;"></img></p>

35、[plannotator](https://hellogithub.com/periodical/statistics/click?target=https://github.com/backnotprop/plannotator)：批注 AI 编码智能体输出的工具。这是一款本地运行的 AI 编程智能体审阅工具。当 AI 输出计划或写完代码后，它会自动在浏览器中打开审查界面，支持批注计划、评论 diff 和 PR，反馈会直接回传给 Agent 执行，兼容 Claude Code、Codex、Copilot CLI 等。

<p align="center"><img src='https://raw.githubusercontent.com/521xueweihan/img4/master/hellogithub/125/1123956658.png' style="max-width:80%; max-height=80%;"></img></p>

### 其它
36、[bee-write-back](https://hellogithub.com/periodical/statistics/click?target=https://github.com/shmimel/bee-write-back)：用树莓派自制一台数字打字机。该项目是用树莓派、5.5 英寸屏幕和机械键盘制作的专注写作设备，作者最初是为了解决睡前写日记助眠、又不想被旧日记勾起情绪的困扰而打造，成本约 200 美元。

<p align="center"><img src='https://raw.githubusercontent.com/521xueweihan/img4/master/hellogithub/125/1187571338.png' style="max-width:80%; max-height=80%;"></img></p>

37、[IHaskell](https://hellogithub.com/periodical/statistics/click?target=https://github.com/IHaskell/IHaskell)：在 Jupyter 中运行 Haskell 代码。该项目能让你在 Jupyter Notebook 中交互式编写和运行 Haskell 代码，支持 GHC 8.4-9.14 所有版本。它提供 Hackage、源码编译、Docker、Nix 等多种安装方式，也可以通过浏览器体验。

<p align="center"><img src='https://raw.githubusercontent.com/521xueweihan/img4/master/hellogithub/125/12373318.png' style="max-width:80%; max-height=80%;"></img></p>

38、[Lithe-IDEA](https://hellogithub.com/periodical/statistics/click?target=https://github.com/1lck/Lithe-IDEA)：轻量级的 Java IDE 编程工具。这是一款面向 Java 和 Spring Boot 开发者的轻量级 IDE，运行时内存占用仅 300-400 MB，支持全局搜索、代码跳转、Maven、断点调试、数据库管理等功能，适用于 macOS 和 Windows 系统。来自 [@Lichenkang](https://hellogithub.com/user/7NYd4yvRlGtqfgr) 的分享

<p align="center"><img src='https://raw.githubusercontent.com/521xueweihan/img4/master/hellogithub/125/1320091816.png' style="max-width:80%; max-height=80%;"></img></p>

39、[mhabit](https://hellogithub.com/periodical/statistics/click?target=https://github.com/FriesI23/mhabit)：跨平台的习惯养成应用。这是一款用于培养和跟踪个人习惯的应用，通过每日打卡帮助用户更高效地养成习惯。它不只统计连续打卡天数，还提供成长曲线量化长期坚持情况，支持 WebDAV 多端同步、自定义颜色和习惯分组，适用于 Android、iOS、Windows、macOS 和 Linux 平台。来自 [@ewiro](https://hellogithub.com/user/iItGgWoJjnLsr0Y) 的分享

<p align="center"><img src='https://raw.githubusercontent.com/521xueweihan/img4/master/hellogithub/125/632693436.png' style="max-width:80%; max-height=80%;"></img></p>

40、[newtab-naivetab](https://hellogithub.com/periodical/statistics/click?target=https://github.com/GXFG/newtab-naivetab)：可视化键盘新标签页。该项目是用键盘布局展示书签的浏览器插件，可将书签和指令绑定到按键，在新标签页中按下对应按键即可直达网站。它内置多种实用小组件，支持拖拽布局、专注模式和云同步，兼容 Chrome、Edge 与 Firefox。来自 [@GXFG](https://hellogithub.com/user/yeYXT1EUJjxwl0S) 的分享
